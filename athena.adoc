== Amazon Athena

> Amazon Athena は、標準 SQL を使用して Simple Storage Service (Amazon S3) 内のデータを直接、簡単に分析できるようにするインタラクティブなクエリサービスです。

- サーバーレスで、インフラストラクチャや管理は不要
- 大規模データに対しても高速なクエリ
- 事前のデータロード不要
- 標準SQLを使用するだけで簡単にクエリを実行
- スキャンしたデータに対しての従量課金

https://aws.amazon.com/jp/athena/features/

=== サーバーレス

- サーバーレスなのでインフラストラクチャを管理する必要がない
- 設定、ソフトウェアの更新が不要
- データセットやユーザー数の拡大によるインフラストラクチャのスケーリングについて心配する必要がない

インフラストラクチャではなくデータに集中できる。
